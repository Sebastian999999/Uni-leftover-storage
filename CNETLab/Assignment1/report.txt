    Accepting a new client connection and creating a new socket for communication with that client.

childPID = fork();

    Forking a child process to handle the client's request concurrently.

if (childPID == 0) {
    // Child process
    close(serverSocket);
    handleClient(newSocket);
    exit(EXIT_SUCCESS);
}

    In the child process, it closes the parent's server socket, handles the client's request using the handleClient function, and exits the child process.

Server-side File Creation:


if (teacherFile != NULL) {
    // The file exists, read its contents and send them back to the teacher
    // ...
} else {
    // The file does not exist, ask the teacher if they want to create it
    // ...
}

    When a teacher connects to the server and provides their course name, the server checks if the corresponding file (course file) exists for that teacher's course.
    If the file exists, the server reads its contents and sends them back to the teacher. This allows the teacher to view the existing information about their course and students.
    If the file does not exist, the server prompts the teacher if they want to create it.


if (strcmp(createResponse, "yes") == 0) {
    // The teacher wants to create the file, create a new file and allow them to add student information
    teacherFile = fopen(filePath.c_str(), "w+");
    fclose(teacherFile);

    const char* successResponse = "Course file created. You can now start adding student information.";
    send(clientSocket, successResponse, strlen(successResponse), 0);
} else {
    const char* failResponse = "Course file not created.";
    send(clientSocket, failResponse, strlen(failResponse), 0);
}

    If the file for the teacher's course does not exist, the server sends a message to the teacher asking if they want to create it. The teacher must respond with "yes" or "no."
    If the teacher responds with "yes," the server creates a new file for that course using the course name provided by the teacher. The file is created with write access so that the teacher can add student information later.
    If the teacher responds with "no," the server informs them that the course file was not created.
